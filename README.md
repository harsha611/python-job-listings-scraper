# Python Job Listings Scraper

This project is a beginner-friendly Python web scraper that collects job listings from the Fake Python Jobs website.

🔗 Project Website: https://realpython.github.io/fake-jobs/

## Features
- Scrapes job title
- Extracts company name
- Gets job location
- Collects job detail page URL
- Stores results in a CSV file

## Technologies Used
- Python
- Requests
- BeautifulSoup (bs4)
- CSV module
